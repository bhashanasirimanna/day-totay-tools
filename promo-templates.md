## 3. Quora: "How do I convert pixels to rem in CSS?"

> Divide the pixel value by the root font size, which is 16px by default. So 24px is 1.5rem and 12px is 0.75rem. If your site changes the root size, use that number instead. Using rem rather than px lets text scale when people raise their browser font size, which helps accessibility. If you do this a lot, I keep a small px to rem converter here: https://www.toolbunch.tools/px-to-rem (I run the site).
